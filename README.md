# Tasks

A clean, fast todo list that runs entirely in the browser. No installs, no build step, no dependencies.

**Live app:** https://donfitex.netlify.app/

## Features

- Add, complete, edit (double-click) and delete tasks
- Priorities: Low, Medium, High
- Due dates chosen from a calendar dropdown, with overdue tasks highlighted
- Progress bar showing how much is done
- Search, plus All / Active / Done filters
- Drag and drop to reorder
- Light and dark themes
- Backup and restore your tasks as JSON (copy and paste)
- Tasks are saved automatically in your browser

## Run it locally

The whole app is one file. Download `todo.html` and open it in any modern browser.

## Notes

- Tasks are stored in your browser's local storage, so they stay on the device and browser you used. Clearing site data removes them, so use Backup / restore to keep a copy.
- Built with plain HTML, CSS and JavaScript.
